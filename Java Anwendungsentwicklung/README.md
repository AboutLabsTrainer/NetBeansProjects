# Java Anwendungsentwicklung

Oberflächen, JDBC und JPA. Die frühere Lücke bei Tag 03 ist in der neuen Nummerierung geschlossen, der Contact Editor ist ein eigenes Modul.

Jedes Modul ist ein Elternordner ohne `pom.xml`. Geöffnet wird der Unterordner mit der `pom.xml` (`codebeispiel`, `uebung-stufe-1`, `uebung-stufe-2`, `loesung/stufe-1`, `loesung/stufe-2`).
