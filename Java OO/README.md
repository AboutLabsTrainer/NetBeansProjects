# Java OO

Objektorientierung am Fuhrpark und an den Mietobjekten: Typen, statische Elemente, Vererbung, Interfaces und Ausnahmen.

Jedes Modul ist ein Elternordner ohne `pom.xml`. Geöffnet wird der Unterordner mit der `pom.xml` (`codebeispiel`, `uebung-stufe-1`, `uebung-stufe-2`, `loesung/stufe-1`, `loesung/stufe-2`).

Anleitung für NetBeans, IntelliJ und VS Code: [Maven-Projekt in der IDE starten](../docs/ide-maven.md).

Workspace-Übersicht: [README.md](../README.md).

- [00-typen](00-typen/README.md) – Typen, Konstruktoren, Casts und Boxing
- [01-static](01-static/README.md) – Statische Zähler, Konstanten und Methoden
- [02-vererbung](02-vererbung/README.md) – Vererbung, Überschreiben und Polymorphie
- [03-interfaces](03-interfaces/README.md) – Interfaces, Default-Methoden und Enums
- [04-ausnahmen](04-ausnahmen/README.md) – Geprüfte Exceptions und Angebotszeilen
