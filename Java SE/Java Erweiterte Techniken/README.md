# Java Erweiterte Techniken

Die Tagesordner sind die Module 00 bis 09. Der Modulordner selbst ist kein Maven-Projekt. Geöffnet wird der Unterordner, in dem die `pom.xml` liegt: `codebeispiel`, `uebung-stufe-1`, `uebung-stufe-2` oder `loesung/stufe-1` und `loesung/stufe-2`.

So starten Sie ein Unterprojekt in NetBeans, IntelliJ oder VS Code: [../../docs/ide-maven.md](../../docs/ide-maven.md)

Kursübersicht: [Java SE](../README.md). Workspace: [README.md](../../README.md).

- [00-listen](00-listen/README.md) – zwei Listen, danach Priorität ohne Duplikat
- [01-sets-maps](01-sets-maps/README.md) – Set, Häufigkeit, Kursbelegung
- [02-generics](02-generics/README.md) – typsichere Sammlung statt Raw Types
- [03-lambda](03-lambda/README.md) – eigene Preisregel, Filter, Supplier
- [04-funktionen](04-funktionen/README.md) – Predicate und Function zusammensetzen
- [05-streams](05-streams/README.md) – filter/map und eine zweite Pipeline
- [06-dateien](06-dateien/README.md) – Text schreiben und CSV-Roundtrip
- [07-threads](07-threads/README.md) – Teilsummen und ein zweites Warten
- [08-sync](08-sync/README.md) – Zähler und Überweisung
- [09-sockets](09-sockets/README.md) – Echo-Zeile und Chat-Empfänger, ohne Netz

Die Lösungen unter `loesung/` sind für den Vergleich nach dem eigenen Versuch.
