# Java-Notizbuch

## Was dieses Beispiel übt

Der kleinste Aufbau eines Java-Programms und die ersten Datentypen: primitive Werte, `String`, ein expliziter Cast und lokale Typinferenz mit `var`.

## In dieser Reihenfolge lesen

1. `MinimalProgram` – Klasse, Dateiname und `main`
2. `JavaNotebook` – Variablen, Cast von `double` nach `int`, `var`, `final`

## Start in NetBeans

Ant-Projekt. Zwei Einstiege: `de.ibb.notebook.MinimalProgram` und `de.ibb.notebook.JavaNotebook`. Die aktive Main-Klasse steht unter Projekteigenschaften, Run. Mit F6 starten.

## Ausprobieren

1. Starte zuerst `MinimalProgram` und prüfe, dass die Klasse und die Datei denselben Namen tragen.
2. Starte `JavaNotebook` und vergleiche `19.99` mit dem abgeschnittenen `int`.
3. Ändere den Radius und starte neu. `PI` bleibt stehen, weil das Feld `final` ist.
