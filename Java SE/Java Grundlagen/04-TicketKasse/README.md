# Ticket-Kasse

## Was dieses Beispiel übt

Ablaufsteuerung in einem kleinen Verkauf: Menü mit `do-while` und `switch`, Preisstaffel mit `if-else-if`, mehrere Tickets mit `for`, Altersprüfung mit `while`.

## Lesen

`TicketKasse` – eine Klasse. Die Preise stehen als `static final` oben, die Tagesstatistik sammelt sich in lokalen Variablen der `main`-Methode.

## Start in NetBeans

Ant-Projekt. Main-Klasse: `de.ibb.controlflow.TicketKasse`. Mit F6 starten und die Fragen auf der Konsole beantworten.

## Ausprobieren

1. Antworte auf den Rabatt-Tag mit `j`, verkaufe ein Kinder- und ein Senioren-Ticket und prüfe den Faktor 0,8 auf der Quittung.
2. Gib beim Alter zuerst `200` ein. Die `while`-Schleife fragt erneut, der Verkauf geht erst nach einem Wert von 0 bis 120 weiter.
3. Wähle `0`. Die Tagesstatistik erscheint erst nach dem Ende der Menüschleife.
