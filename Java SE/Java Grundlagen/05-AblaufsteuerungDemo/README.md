# Ablaufsteuerung

## Was dieses Beispiel übt

Dieselben Steueranweisungen wie in der Ticket-Kasse, aber einzeln hintereinander: Note mit `if-else-if`, Wochentag mit `switch`, Zahlenraten mit `do-while`, Einmaleins mit `for`. Die Eingabeprüfung davor ist jeweils eine `while`-Schleife.

## Lesen

`AblaufsteuerungDemo` – vier Aufgaben in `main`, in der Reihenfolge des Programms.

## Start in NetBeans

Ant-Projekt. Main-Klasse: `de.ibb.flow.AblaufsteuerungDemo`. Mit F6 starten.

## Ausprobieren

1. Gib zuerst eine Note außerhalb von 1 bis 6 ein. Die Schleife wiederholt die Frage.
2. Rate die Geheimzahl. Sie steht als `final int secret = 4` im Quelltext. Die Schleife endet erst beim Treffer.
3. Lass das Einmaleins für 7 ausgeben und prüfe die letzte Zeile: `7 x 10 = 70`.
