# Java SE – Grundlagen

Module `00` bis `07`. In jedem Modul liegen `codebeispiel`, `uebung-stufe-1`, `uebung-stufe-2` und `loesung`. Geöffnet wird der Ordner mit der `pom.xml`.

Die Schritte für NetBeans, IntelliJ und VS Code stehen in [docs/ide-maven.md](../../docs/ide-maven.md).

| Modul | Thema |
|-------|--------|
| `00-notebook` | Erstes Programm, Variablen, `final` |
| `01-typen` | Primitive Werte und Referenzen |
| `02-text-zeit` | String und Date-Time |
| `03-ticketkasse` | Preise und Rabatt |
| `04-ablaufsteuerung` | Verzweigung und Hinweis |
| `05-debug` | Rechenfehler finden |
| `06-debug-zahlen` | Array-Grenzen |
| `07-buchverwaltung` | Klasse `Buch` und Regal |
