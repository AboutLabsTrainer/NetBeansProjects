# Java SE

Kern der Sprache, bevor Frameworks dazukommen. Zwei nummerierte Folgen, jeweils mit eigenen Modulen. `Java ist auch eine Insel` gehört nicht dazu.

Geöffnet wird der Unterordner mit der `pom.xml`, nicht der Elternordner des Moduls. Anleitung: [Maven-Projekt in der IDE starten](../docs/ide-maven.md).

Workspace-Übersicht: [README.md](../README.md).
