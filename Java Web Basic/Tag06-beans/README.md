# Tag6 – JavaBeans, Actions & Direktiven (Jakarta Pages/JSP)
Namespace: de.ibb · Projektname: Tag6

## Import & Start
1) NetBeans → Datei → Öffnen → `pom.xml` wählen
2) Run/Deploy auf Payara 7
3) Start: `http://localhost:8080/Tag6/`

## Übungsübersicht
- Beans: `PersonBean`, `CounterBean`
- Actions: `jsp:useBean`, `jsp:setProperty property="*"`, `jsp:getProperty`, `jsp:include`, `jsp:forward` + `jsp:param`
- Direktiven: `@page errorPage`, `@include` (Header/Footer)
- Scopes: `request` (Form-Bean), `session` (Counter)
