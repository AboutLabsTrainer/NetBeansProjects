# NetBeansProjects

Private workspace for Java training materials used with NetBeans and related tooling.

## Layout

| Folder | Focus |
|--------|--------|
| `Java SE` | Language basics, advanced techniques, book samples |
| `Java OO` | Object-oriented exercises |
| `Java Anwendungsentwicklung` | Desktop / JDBC / JPA labs |
| `Java Web Basic` | Servlets, JSP, MVC intro |
| `Java Web Aufbau` | Filters, JPA relations, Java EE |
| `Spring Boot Basic` | Spring Boot fundamentals |
| `Spring Boot AK` | Security, messaging, actuators, microservices |
| `Mini Projekte` | Small scratch and demo projects |
| `Rheinwerk` | Book sample code |
| `Tmp` | Experiments and temporary work |
| `Debug` | Debugging scratch space |

## Notes

- Build outputs (`target/`, `build/`, `dist/`, …), IDE private files, local broker data, and archives (`.zip`, …) are ignored.
- Prefer unpacked project sources over archive copies in the tree.
