# Java ist auch eine Insel

Das sind die Buchbeispiele von Christian Ullenboom. Sie bleiben absichtlich unverändert, damit sie zur jeweiligen Stelle im Buch passen.

Zum Nachschlagen den Themenordner öffnen, der zum Kapitel gehört. Die Beispiele liegen unter `programs-on-the-island`, im Paket `com.tutego.insel` (etwa `io`, `lambda`, `thread`, `net`). Die Kapitelquellen nicht umschreiben und nicht an die eigenen Labs anpassen.
