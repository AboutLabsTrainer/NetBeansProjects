# FreeMarker Demo

Spring Boot Demo-Projekt mit **FreeMarker** Template Engine.

## 🚀 Schnellstart

```bash
mvn spring-boot:run
```

Öffne: `http://localhost:8081`

## 📋 Features

- ✅ 50 zufällige Personen via DataFaker
- ✅ FreeMarker Template Engine
- ✅ Responsive Design
- ✅ Spring Boot 3.2.0
- ✅ Java 21

## 🎯 Über FreeMarker

FreeMarker ist eine Enterprise-Template-Engine. Sie bietet:
- Mächtige Template-Sprache
- Große Flexibilität
- Weit verbreitet in Enterprise-Anwendungen
- Ausgereifte, stabile Technologie
