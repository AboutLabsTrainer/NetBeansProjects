# Groovy Templates Demo

Spring Boot Demo-Projekt mit **Groovy Templates** Template Engine.

## 🚀 Schnellstart

```bash
mvn spring-boot:run
```

Öffne: `http://localhost:8083`

## 📋 Features

- ✅ 50 zufällige Personen via DataFaker
- ✅ Groovy Templates Template Engine
- ✅ Responsive Design
- ✅ Spring Boot 3.2.0
- ✅ Java 21

## 🎯 Über Groovy Templates

Groovy Templates nutzen die Kraft von Groovy. Sie bieten:
- DSL-basierte Template-Sprache
- Elegante, ausdrucksstarke Syntax
- Volle Groovy-Power in Templates
- Gut für Groovy-Fans
