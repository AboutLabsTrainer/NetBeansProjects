# JSP Demo

Spring Boot Demo-Projekt mit **JSP** Template Engine.

## 🚀 Schnellstart

```bash
mvn spring-boot:run
```

Öffne: `http://localhost:8086`

## 📋 Features

- ✅ 50 zufällige Personen via DataFaker
- ✅ JSP Template Engine
- ✅ Responsive Design
- ✅ Spring Boot 3.2.0
- ✅ Java 21

## 🎯 Über JSP

JSP (JavaServer Pages) ist eine Legacy-Technologie. Sie ist:
- Wichtig für Wartung alter Anwendungen
- Nutzt JSTL (JSP Standard Tag Library)
- Nicht mehr empfohlen für neue Projekte
- Aber immer noch weit verbreitet
