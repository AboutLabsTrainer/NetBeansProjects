# JTE Demo

Spring Boot Demo-Projekt mit **JTE** Template Engine.

## 🚀 Schnellstart

```bash
mvn spring-boot:run
```

Öffne: `http://localhost:8082`

## 📋 Features

- ✅ 50 zufällige Personen via DataFaker
- ✅ JTE Template Engine
- ✅ Responsive Design
- ✅ Spring Boot 3.2.0
- ✅ Java 21

## 🎯 Über JTE

JTE (Java Template Engine) ist eine moderne Template-Engine. Sie bietet:
- Type-Safety zur Compile-Zeit
- Kompiliert zu Bytecode - extrem schnell!
- Hot-Reload während der Entwicklung
- Beste Performance aller Template-Engines
