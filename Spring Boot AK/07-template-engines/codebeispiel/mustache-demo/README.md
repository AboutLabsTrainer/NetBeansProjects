# Mustache Demo

Spring Boot Demo-Projekt mit **Mustache** Template Engine.

## 🚀 Schnellstart

```bash
mvn spring-boot:run
```

Öffne: `http://localhost:8085`

## 📋 Features

- ✅ 50 zufällige Personen via DataFaker
- ✅ Mustache Template Engine
- ✅ Responsive Design
- ✅ Spring Boot 3.2.0
- ✅ Java 21

## 🎯 Über Mustache

Mustache ist eine logikfreie Template-Engine. Sie bietet:
- Einfachste Template-Syntax
- Logikfrei - nur Platzhalter
- Isomorph (Java, JavaScript, etc.)
- Perfekt für einfache Use-Cases
