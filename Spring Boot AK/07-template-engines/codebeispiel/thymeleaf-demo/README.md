# Thymeleaf Demo

Spring Boot Demo-Projekt mit **Thymeleaf** Template Engine.

## 🚀 Schnellstart

```bash
mvn spring-boot:run
```

Öffne: `http://localhost:8080`

## 📋 Features

- ✅ 50 zufällige Personen via DataFaker
- ✅ Thymeleaf Template Engine
- ✅ Responsive Design
- ✅ Spring Boot 3.2.0
- ✅ Java 21

## 🎯 Über Thymeleaf

Thymeleaf ist die Standard-Template-Engine für Spring Boot. Sie bietet:
- Natural Templates (öffnen direkt im Browser)
- Starke Spring-Integration
- Server-seitiges Rendering
- Große Community
