# Pebble Demo

Spring Boot Demo-Projekt mit **Pebble** Template Engine.

## 🚀 Schnellstart

```bash
mvn spring-boot:run
```

Öffne: `http://localhost:8084`

## 📋 Features

- ✅ 50 zufällige Personen via DataFaker
- ✅ Pebble Template Engine
- ✅ Responsive Design
- ✅ Spring Boot 3.2.0
- ✅ Java 21

## 🎯 Über Pebble

Pebble ist eine moderne, Twig-ähnliche Template-Engine. Sie bietet:
- Twig-ähnliche Syntax (aus PHP bekannt)
- Schnelle Performance
- Hervorragende Error-Messages
- Aktive Community

**Von Java Fleet** - Spring Boot Aufbau Kurs
