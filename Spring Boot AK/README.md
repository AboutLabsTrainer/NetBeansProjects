# Spring Boot AK

Jedes Thema ist ein Elternordner ohne eigene `pom.xml`. Geöffnet wird `codebeispiel`, `uebung-stufe-1`, `uebung-stufe-2` oder ein Ordner unter `loesung`.

Vor dem nächsten Programm den vorherigen eingebetteten Tomcat beenden, sonst bleibt der Port belegt.

IDE und Maven: [Maven-Projekt in der IDE starten](../docs/ide-maven.md).

Workspace-Übersicht: [README.md](../README.md).
