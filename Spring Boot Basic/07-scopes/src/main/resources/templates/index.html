Singleton, Prototype, Request, Session und Application Scope im Vergleich.

Was sind Bean Scopes?

Scopes in Spring bestimmen, wie lange eine Bean lebt, wann neue Instanzen erzeugt werden und ob mehrere Requests bzw. User sich eine Instanz teilen.

  • Singleton – eine Instanz pro Anwendung (Standard)
  • Prototype – neue Instanz bei jedem Abruf
  • Request – eine Instanz pro HTTP-Request
  • Session – eine Instanz pro HTTP-Session (User)
  • Application – eine Instanz pro Web-Anwendung
